# 🎓 Excel VBA Certificate Generator

🚀 An automated certificate generation system built using **Excel VBA**, **Microsoft Word Automation**, and **PDF Export** technology.

This project eliminates manual certificate creation by automatically reading candidate information from an Excel dataset, replacing placeholders in a Word certificate template, and generating personalized PDF certificates in bulk.

## ✨ Key Features

✅ Bulk certificate generation from Excel data

✅ Dynamic Word template selection

✅ Automatic placeholder replacement

✅ Support for Word text boxes and shapes

✅ One-click PDF export for each candidate

✅ Custom file naming using Candidate ID

✅ User-friendly folder and template selection dialogs

## 🛠️ Technologies Used

* Microsoft Excel VBA
* Microsoft Word Automation
* PDF Export Automation
* File System Operations

## 📊 Business Impact

🔹 Reduced manual certificate preparation time

🔹 Improved accuracy by eliminating repetitive data entry

🔹 Enabled scalable certificate generation for training programs, workshops, educational institutions, and corporate events

## 📂 Sample Workflow

1️⃣ Select the certificate template (.docx)

2️⃣ Select the destination folder

3️⃣ Read candidate data from Excel

4️⃣ Replace certificate placeholders automatically

5️⃣ Generate individual PDF certificates

6️⃣ Save certificates using Candidate ID
